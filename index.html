Quick reference: formulas and modes

The Mid capsule points forward. The Side capsule is a figure-8: its left lobe gives positive polarity, its right lobe negative polarity — but both arrive in one signal. So S cannot be separated into two independent recordings; its "left" and "right" halves are the same signal with opposite polarity:

S_left = +S S_right = −S

Combining with M gives normal stereo. The width control scales S:

L = M + width·S R = M − width·S

Going the other way, any L/R stereo file can be turned back into M/S:

M = (L + R) / 2 S = (L − R) / 2

Modes: MS raw expects M on channel 1 and S on channel 2 (Zoom's "MS-RAW"). Stereo L/R → M/S is for files that were already decoded to stereo. Split channels just writes each channel as its own mono file (use it for the XY file). The XY file is already L and R and is not part of the MS equation: decoding MS only ever uses M and S. If the stereo image sounds mirrored compared with the XY file, tick Invert S.
